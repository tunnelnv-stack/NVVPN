# NVVPN — Windows x64 (локальная интеграция обновлений)

Клиент для подключения к VPN-серверу по отдельному профилю устройства. Всё поддерживаемое соединение идёт через VPN; выбранные приложения и сайты из раздела «Без VPN» выходят напрямую. Автоподключения нет.

## Установка и обновление

Нужны Windows 10 1903 / Windows 11 x64 и .NET Framework 4.8. Установщик NVVPN-Setup-X.Y.Z-x64.exe автономный, среда разработки для работы не нужна. Архив NVVPN-X.Y.Z-Windows-x64.zip содержит то же приложение: распакуйте его целиком.

Перед обновлением вручную отключите прежнее соединение NVVPN и выберите «Выход» в трее. Установщик блокирует замену файлов работающего клиента. Не запускайте две версии одновременно. Установщик сохраняет идентификатор приложения предыдущих выпусков; профили и правила остаются в прежнем хранилище. Фактическое обновление на вашей системе ещё требует ручной проверки.

Откройте NVVPN и подтвердите запрос Windows в той же учётной записи. Отмена закрывает приложение; подтверждение UAC не запускает VPN. Старый клиент Finland VPN не заменяется и не останавливается автоматически.

## Первое подключение

1. На новом ПК выберите «Добавить профиль .conf». В пакете нет пользовательских профилей. Для каждого одновременно работающего устройства нужен отдельный профиль и пара ключей.
2. Выберите обычный Ethernet или Wi-Fi. Если используется другой VPN, переключение выполните вручную, учитывая возможный обрыв связи.
3. Нажмите «Подключиться». При первом подключении прочитайте условия и конфиденциальность редакции 1.1, поставьте галочку и нажмите «Принять и подключиться». Галочка изначально снята. Отказ не включает VPN. После изменения текста требуется повторное принятие.
4. Кнопка остановки отключает соединение. Закрытие окна во время соединения сворачивает приложение в трей; «Выход» завершает соединение и приложение.

Обычное подключение не ограничено двумя минутами. Постоянного kill switch нет: после остановки VPN восстанавливается обычная сеть. Отключение и повторное включение другого VPN выполняются пользователем.

## Исключения и настройки

В «Без VPN» добавляйте домены без https:// и пути, по одному в строке, и полные пути к .exe. Есть общая настройка учёта поддоменов. Совпадение приложения ИЛИ домена даёт прямое соединение. Пустые списки означают полный туннель. Нераспознанное имя назначения не переводится автоматически в прямое соединение. Сохранённые изменения применяются при следующем подключении; ранее открытые соединения может потребоваться открыть заново.

Совместимость YouTube по умолчанию включена; сохранённый выбор имеет приоритет. Она ограничивает UDP/443 для распознанных направлений YouTube, чтобы браузер использовал TCP. Эти направления остаются через VPN, кроме явных исключений. Это не гарантия скорости или качества видео.

Технический журнал по умолчанию выключен при каждом запуске. В настройках можно включить запись до закрытия программы, открыть журнал и очистить журналы. Кнопка очистки удаляет также старый test-events.txt, но не профили, правила, согласие или DNS-кэш. Размер нового журнала ограничен 1 МиБ; при достижении предела запись начинается заново. Автоматической отправки журнала нет.

## Данные и условия

Профили и правила сохраняются в %LOCALAPPDATA%\NeverVPN с защитой DPAPI CurrentUser. Имя папки оставлено для совместимости. Принятие условий хранится в agreement.dpapi. DNS/fake-IP кэш защищён правами доступа и может содержать домены. Пользовательские данные сохраняются при удалении программы. Настройки и сроки серверных журналов не определяются этим клиентом; обещания «никаких логов» для всей инфраструктуры нет.

Условия доступны через «О программе» → «Условия и конфиденциальность». Контакт NVVPN: tunnelnv@gmail.com. Не отправляйте приватные ключи в поддержку.

## Обновления через GitHub

В настройках нажмите «Проверить обновления». Клиент обращается к публичным Releases tunnelnv-stack/NVVPN без токенов, пропускает предварительные версии и проверяет подпись издателя. До первой публикации сообщение о недоступном выпуске ожидаемо. Проверка и загрузка VPN не отключают. Установка начинается после отдельного согласия на завершение NVVPN и штатного выхода движка. Подпись, размер и SHA-256 проверяются повторно перед запуском.

Установленная версия обновляется автономным Inno Setup. Portable распаковывается в новую папку рядом с прежней. Профили, исключения, условия и настройки остаются в прежнем DPAPI-хранилище. Прежде чем менять файлы, координатор сохраняет старый комплект и копию данных в `%PROGRAMDATA%\NVVPN\Backups`. Резервные копии защищены правами администратора и автоматически не удаляются. Для ручного возврата завершите NVVPN и откройте `app\NVVPN.exe` из копии, не включая одновременно другую версию. Копию `data` не восстанавливайте поверх новых профилей без отдельного решения.

При ошибке установщика координатор пытается восстановить прежние файлы приложения; регистрацию Inno при необходимости исправляют сохранённым старым установщиком. Автоматического подключения после установки или ошибки нет. Кнопка «Исходный код на GitHub» ведёт к конкретной версии; до публикации доступна также кнопка локального архива. Вопросы лицензий публичного распространения ещё не закрыты.
