Проект для утверждения владельцем. Этот документ не предоставляет новую лицензию и не меняет лицензии зависимостей.

До выбора подтвердить состав авторских прав на C#/WPF-оболочку, общие исходники, установщик, графику и прочие собственные материалы; не выдумывать имя правообладателя или год начала авторства. Отдельно проверить происхождение заимствований. Публичное название остаётся NVVPN; правообладатель и товарное обозначение — разные сведения.

Движок с маршрутизатором уже распространяется как GPL-3.0-or-later. Отдельный процесс C# и обмен через stdin/IPC сами по себе не устанавливают независимость произведений: важны фактическая интеграция, протокол и степень зависимости. [Пояснение GNU о сочетании и агрегировании](https://www.gnu.org/licenses/gpl-faq.html#MereAggregation), [GPLv3](https://www.gnu.org/licenses/gpl-3.0.html).

Варианты решения владельца после проверки прав:

1. Для собственного кода выбрать GPL-3.0-or-later, сохранить исключения/лицензии сторонних файлов, добавить точные copyright notices. Это не решает автоматически отдельные ограничения Wintun.
2. Для действительно самостоятельной оболочки выбрать отдельную разрешительную лицензию, например MIT, только после оценки GPL-границы и согласия всех нужных правообладателей. Сторонние компоненты остаются под собственными лицензиями.
3. Отложить выбор; оставить данный выпуск локальным проектом. Наличие исходников в ZIP не означает выдачу получателю необходимых прав на собственный код и не является основанием объявить выпуск готовым для передачи.

Владелец должен утвердить: охваченные файлы, правообладателя, годы, лицензию и допустимый объём распространения. После решения добавить отдельный LICENSE собственного кода и заголовки там, где необходимо. Соглашение о серверном доступе не должно ограничивать GPL-права на код; условия бесплатного тестирования не заменяют программную лицензию.
