# Сторонние компоненты: оценка публикации 0.4.4 и 0.4.5

Проверено 19 ноября 2026 года, уточнено после сверки официальных архивов Wintun
и WinDivert. Сценарий — личное использование и бесплатная передача семье.
Это техническая оценка условий; спорная GPL-граница отмечена как неопределённость,
а не доказанное нарушение или безусловная обязанность запрашивать разрешение.

## GPL: состав и способ выдачи

GPLv3 §1, §4–6 требуют соответствующие исходники, изменения и нужные сценарии
сборки/установки. Для планируемой загрузки из интернета выбирается §6(d): явная
бесплатная ссылка на полный Source ZIP на той же странице Release, без аккаунта
и токена. Автоматический GitHub Source code.zip не заменяет этот архив.
Уведомления и лицензионное дополнение должны сопровождать оба выпуска.

Собственный код разрешён под GPL-3.0-or-later решением владельца от 19.11.2026.
Это снимает неопределённость выбора лицензии оболочки; не требуется основывать
публикацию на неподтверждённом утверждении о её независимости от GPL-движка.

## WinDivert 2.2.2: конкретный путь выполнения LGPL

Используем ветку LGPLv3, сохраняя оригинальное предложение альтернативной GPL.
Полные GPLv3/LGPLv3 и официальный C/WDK-архив v2.2.2 уже включены в Source ZIP.
Происхождение официальных SYS и заголовка сверено в WINDIVERT-OFFICIAL-HASHES.json.
В лицензионное дополнение вынесены явное уведомление об использовании WinDivert,
исходные copyright-строки и инструкция пересборки.

Для встроенного asset не полагаемся на вариант shared library из §4(d)(1).
Выбран путь §4(d)(0): полный исходный код библиотеки и приложения, позволяющий
пересобрать комбинированное произведение. GPL собственного кода разрешает
изменения и отладку, включая reverse engineering для отладки изменений библиотеки.
Проверки SHA не объявляются запретом пользовательской модификации: при собственной
сборке хеши пересоздаются, официальный ключ издателя не нужен.

Процедура: извлечь WinDivert-2.2.2-source.zip, использовать upstream README и
wddk-build.bat с WDK в отдельной Windows-среде; подготовить изменённый драйвер;
сделать локальную копию модуля sing-box и go.mod replace на неё; заменить
common/windivert/assets/WinDivert64.sys и согласовать Asset64SHA256 в этом модуле;
пересобрать движок и оболочку штатным build.ps1. Не редактировать глобальный
module cache. Имена конкретных констант проверяются по включённой версии модуля.
Подпись изменённого SYS должна соответствовать требованиям тестовой Windows;
чужой закрытый ключ не предоставляется. Системный test mode на рабочем ПК не включать.

Поставка скачиваемого приложения сама по себе не является передачей владения
компьютером. Требование Installation Information GPLv3 §6 / LGPLv3 §4(e)
проверяется заново при продаже/передаче User Product или ином изменении модели.
Запрет модификации и отладки библиотеки в пользовательские условия не добавлен.

Технический состав для этого пути подготовлен. Сборка и запуск изменённого SYS
не проверены; работоспособность замены в тестовой Windows — остающийся пункт
проверки, а не требование получать коммерческую лицензию. LGPLv3 уже разрешает
использование/распространение при выполнении перечисленных условий. Отдельный
запрос или покупка лицензии для выбранного пути не требуются.

## Wintun: разрешение DLL и отдельный вопрос GPL-границы

Официальный сайт различает GPLv2 исходников и отдельную лицензию подписанных DLL:
https://www.wintun.net/ . В состав Source ZIP тоже входит готовая DLL, поэтому
название архива «исходники» не устраняет этот вопрос.

Официальный ZIP 0.14.1 заново получен с wintun.net/builds. SHA-256 всего архива:
07c256185d6ee3652e09fa55c0b673e2624b565e02c4b9091c79ca7d2f24ef51.
Его LICENSE.txt побайтно равен сохранённому тексту, AMD64 DLL — внешней DLL
0.4.3/0.4.4/0.4.5 и байтам внутри движков. Все пять копий DLL в каждом Source ZIP
совпадают с соответствующей архитектурой официального архива. Проверка Authenticode
внешней DLL: Valid, WireGuard LLC, версия 0.14.1. Все 14 используемых API-функций
соответствуют typedef из официального wintun.h.

Пункт 3(d) содержит исключение из необходимости предварительного письменного
согласия для распространения DLL вместе с ПО, использующим только Permitted API.
Пункт 3(b) также сохраняет исключение для использования API. Значит, обычная
поставка проверенной неизменённой DLL с NVVPN уже разрешена лицензией; отдельный
запрос правообладателю для этого не нужен. Требования «только коммерческая лицензия»
или «обязательно письменное разрешение» в данном сценарии из текста не следуют.
Нужно сохранить notices, не изменять DLL и не приписывать WireGuard одобрение NVVPN.

DLL в sing-tun дополнительно хранится неизменёнными байтами в EXE и загружается
memmod.LoadLibrary. Прямого запрета embedding/memmod в лицензии не найдено.
Обычные relocations при загрузке не объявляются здесь нарушением запрета изменения.
Из одного нестандартного загрузчика нельзя делать вывод о необходимости письма.
Соответствие побайтовых копий и API установлено; запрет такой упаковки не установлен.

Отдельно: разрешение поставлять DLL не является утверждением, что её условия
превратились в GPL. В бинарной лицензии есть запреты модификации/reverse engineering,
в GPLv3 §5/§10 — требования к охваченному произведению и дополнительным ограничениям.
Если считать DLL и GPL-движок единым производным произведением, возникает вопрос
совместимости; если самостоятельными работами, вывод другой. В этом аудите нет
достаточного основания окончательно установить такую правовую границу. Это
**неопределённость всей комбинации, а не обнаруженное нарушение Wintun и не
обязательная предварительная переписка**. Нельзя ни гарантировать полное GPL-
соответствие на основании одного §3(d), ни объявлять распространение запрещённым
только из-за наличия двух лицензий. Рабочую реализацию по этой причине не меняем.

Запрос правообладателю не отправляется; прежний черновик оставлен только как
исторический материал. Для личного использования специальное согласование не
требуется. При передаче копий семье нужно предоставить соответствующие исходники
и лицензии; бесплатность и родство сами по себе не отменяют GPL/LGPL. Публичная
публикация остаётся отдельным действием с разрешения владельца и с явным
отражением оставшейся GPL-неопределённости, а не с выдуманным требованием письма.
